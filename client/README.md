# Taze Kuru Client

Bu klasör TazeKuru projesinin frontend (istemci) kodlarını içerir.

## Kurulum

1. Bağımlılıkları yükleyin:
```bash
npm install
```

2. Uygulamayı başlatın:
```bash
npm start
```

## Yapılandırma

Uygulama varsayılan olarak `http://localhost:8081` adresindeki backend sunucusuna istek atar. Google Maps API anahtarı ve diğer ayarlar için gerekli düzenlemeleri yapabilirsiniz.

## Teknolojiler

- React 19
- Tailwind CSS
- React Router DOM
- Axios
